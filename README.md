# 河道浅滩水流 3D 仿真

基于原生 Three.js + OrbitControls 的水利简易可视化页面。所有地形、水面、岩石、杂草和浮标均为程序化低模/着色器生成，最终 `index.html` 已内联 Three.js r147 与 OrbitControls，可直接双击在现代 Chrome / Edge 中离线打开。

## 运行

直接打开：

```text
index.html
```

无需 npm、构建工具或本地服务器。

## 交互

- 左键拖拽：旋转视角
- 滚轮：缩放
- 右键拖拽：平移
- 流速滑块：同步改变水面波纹时间流速与浮标运动速度
- 水位滑块：整体抬升/下降水面，并实时计算沙洲采样点的淹没比例
- 粒子数量：支持 160 / 360 / 600 三档，并可单独显示或隐藏浮标
- 水面开关：显示或隐藏水体

## 实现要点

- 统一的确定性高程函数驱动地形网格、高程数据纹理、粒子搁浅判断和植被/石块摆放。
- 水面使用 `MeshStandardMaterial.onBeforeCompile` 注入波纹法线、水深配色、岸线 `discard` 和浅水泡沫，同时保留 Three.js 光照、雾与软阴影接收。
- 浮标流场综合河道切线、固定横向路径、河床坡度、等高线绕流、岸边约束和礁石圆形碰撞。
- 岩石与杂草使用低面数几何体和 `InstancedMesh`，阴影贴图为 2048²，并限制设备像素比以保持流畅。
